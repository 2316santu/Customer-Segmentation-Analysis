Customer Segmentation Analysis
 Project Overview
This project focuses on segmenting customers based on their income and spending behavior using Python. The goal is to identify different customer groups and provide business insights for targeted strategies.

Features
- Data analysis using Pandas  
- Rule-based customer segmentation  
- K-Means clustering for advanced segmentation  
- Visualization using scatter plots  
- Cluster centroid analysis 

 Tools & Technologies
- Python  
- Pandas  
- Matplotlib  
- Scikit-learn
- 
 Key Insights
- High-value customers generate the most revenue  
- High-income low-spending customers are potential targets  
- Mid-segment customers can be converted into high-value  
- Low-value customers need engagement strategies  

Files Included
- `customer_segmentation_analysis.ipynb`  
- `customer_data.csv`
